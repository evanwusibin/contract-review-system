# 经营归因系统 · G1 原型评审与界面状态契约

> **状态**：draft。本文定义合同评审工作台的页面状态与交互契约。
>
> 注：合同评审项目当前使用 `contract-review-ui/` 零依赖静态前端。

## 1. 页面状态

| 状态编号 | 名称 | 触发条件 | 用户可见元素 |
|---|---|---|---|
| P-01 | 工作台首页 | 进入工作台 | 待审任务列表、操作按钮 |
| P-02 | 导入页 | 点击"导入合同" | 文件上传区、基本信息表单 |
| P-03 | 解析中 | 导入后解析运行中 | 进度条、阶段提示 |
| P-04 | 解析结果（可审） | 解析成功 | 左原文/右审核双栏、字段清单 |
| P-05 | 阻塞（低清/损坏） | 质量诊断失败 | 阻塞原因、重新上传入口 |
| P-06 | 风险展示 | 规则命中 | 风险清单、证据定位、建议结论 |
| P-07 | 会签确认 | 进入确认环节 | 角色列表、确认/驳回按钮 |
| P-08 | 版本时间线 | 点击"版本" | 版本列表、切换按钮 |

## 2. 关键交互约束

- 左原文点击证据 → 右侧展开对应规则和处理建议
- 右侧点击风险项 → 左侧跳转到对应页码/段落
- 低清页显示质量标记，不可定位时明确提示
- `SIMULATED_ONLY` 标记在所有模拟操作中可见
- 确认操作前必须展示 `required_roles` 和已确认角色

## 3. 状态机映射

```
P-01 → P-02 → P-03 → P-04 → P-06 → P-07 → P-08
                 ↓
               P-05 (阻塞)
```
