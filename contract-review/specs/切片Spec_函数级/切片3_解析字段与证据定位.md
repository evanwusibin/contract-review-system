# 切片3 · 解析字段与证据定位

## 目标

对可解析 PDF 返回字段值、置信度、原文片段和页码；解析失败返回错误而不是空字段。

## 函数级Spec

### `parse_document(attachment_id, strategy)`

| 项 | 契约 |
|---|---|
| 输入 | 附件ID、解析策略 |
| 输出 | `parse_id`、`extracted_payload`（含字段/证据/置信度）、`quality_score` |
| 字段结构 | 每个字段含 `value`、`status`、`confidence`、`evidence`（页码+片段） |
| 异常 | provider 超时最多重试 3 次，最终失败进入 `blocked` |

### `extract_fields(parse_result)`

提取：合同标题、编号、签约主体、对方名称、金额、币种、生效/到期时间、付款条款、质保责任等。

## 验收测试

- GD-001 能提取最小字段集
- 每个字段有 `value/status/confidence/evidence`
- 低置信度字段不被视为确定事实
