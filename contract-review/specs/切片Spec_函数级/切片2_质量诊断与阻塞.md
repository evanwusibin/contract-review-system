# 切片2 · 质量诊断与阻塞

## 目标

低清、空页、损坏文件被明确标记，用户知道重新上传或人工补录的下一步。

## 函数级Spec

### `diagnose_quality(file, attachment_id)`

| 项 | 契约 |
|---|---|
| 输入 | 文件流、附件ID |
| 输出 | `quality_status`、`quality_score`、`page_issues`（页码列表） |
| 质量等级 | `usable` / `low_quality` / `unreadable` |
| 异常 | 损坏文件 → `blocked`，不得进入规则判断 |

## 验收测试

- 低清案例显示页码、质量分和原因
- 损坏文件进入 `blocked`
- 重试最多 3 次，失败后保留原因
