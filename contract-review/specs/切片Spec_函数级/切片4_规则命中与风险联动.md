# 切片4 · 规则命中与风险联动

## 目标

缺失乙方时命中主体完整性规则，右侧显示高风险，点击风险可以定位左侧证据。

## 函数级Spec

### `execute_rules(parse_id, contract_type, ruleset_version)`

| 项 | 契约 |
|---|---|
| 输入 | 解析ID、合同类型、规则集版本 |
| 输出 | `rule_hits` 列表（每条含 rule_id、severity、message、evidence） |
| 结果类型 | `hit` / `not_hit` / `insufficient_evidence` |
| 约束 | `insufficient_evidence` 不伪造命中；规则缺失返回 `RULESET_NOT_AVAILABLE` |

### `compute_risk_level(rule_hits)`

根据命中规则的最高 severity 计算整体风险等级。

## 验收测试

- `RULE-PARTY-001` published 后可稳定复现命中
- 命中包含规则版本、等级、说明、页码和片段
- 证据不足输出 `insufficient_evidence`
