# 切片5 · 建议结果与会签

## 目标

系统生成建议驳回/人工复核，分派责任角色；缺少任一角色确认时不能完成结果确认。

## 函数级Spec

### `generate_recommendation(task_id, rule_hits)`

| 项 | 契约 |
|---|---|
| 输入 | 任务ID、规则命中列表 |
| 输出 | `recommendation`（pass/reject/manual_review）、`required_roles` |
| 规则 | 有 high severity 命中 → `reject`；有 medium → `manual_review`；仅 low → `pass` |

### `confirm_result(task_id, result_id, role, comment)`

| 项 | 契约 |
|---|---|
| 输入 | 任务ID、结果ID、确认角色、意见 |
| 输出 | 更新后的 `confirmed_roles` |
| 约束 | 未完成全部会签时拒绝 `confirmed`；驳回/补证退回 `reviewing` |

### `write_comment(task_id, result_id, actor_id, role, action, comment)`

写入 `comment_logs`，记录操作者、角色、动作、意见、前后状态。

## 验收测试

- 高风险生成 `reject` 建议但状态仍为待确认
- 多角色分派正确
- 未完成全部会签时拒绝 `confirmed`
- 驳回/补证退回 `reviewing`
