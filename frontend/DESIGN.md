# 合同评审工作台设计契约

## 1. 唯一视觉基准

`02_合同评审开发任务/合同评审工作台_阶段1原型.html` 是前端唯一视觉与交互权威来源。实现不得自行改成通用仪表盘、Emoji 导航或卡片堆叠风格。

## 2. 页面骨架

- 根节点必须使用 `.app`：`220px` 固定侧栏 + 剩余宽度主内容。
- 侧栏高度 `100vh`，主内容首屏可见，不得被侧栏推到视口下方。
- 顶栏高度 `64px`；内容区最大宽度 `1540px`，可纵向滚动。
- 评审详情使用双栏 `.workspace`：左侧原文证据，右侧结构化字段、风险、建议和会签。

## 3. 视觉 Token

- 主文本 `#1e293b`，次文本 `#64748b`，弱文本 `#94a3b8`。
- 主色 `#2563eb`，辅助紫 `#7c3aed`，成功 `#16a34a`，警告 `#d97706`，风险 `#dc2626`。
- 页面背景：`linear-gradient(135deg,#eef4ff 0%,#f4f1ff 42%,#effaf6 100%)`。
- 卡片圆角 `14px`，阴影 `0 8px 28px rgba(30,41,59,.07)`。
- 登录视觉区：`7fr / 3fr`，渐变 `#e90055 → #bd0acb → #2424d8`。

## 4. 图标

- 所有功能图标使用内联 SVG symbol；禁止 Emoji、字符图标和外部不受控图标 URL。
- SVG 使用统一 `16×16` 线性描边，`stroke-width:1.8`。
- 当前 symbol：home、inbox、file、history、rules、shield、users、search、spark、refresh、logout。

## 5. 页面与状态

- 登录页：登录成功/失败、注册提示、找回密码提示。
- 首页：6 个能力卡、3 个场景、5 步流程、真实任务统计。
- 待审任务：真实任务列表、刷新、导入、状态徽标。
- 合同文档：KPI、文档表格、进入双栏评审。
- 双栏评审：解析质量、证据片段、结构化字段、风险、建议、会签。
- 合同版本：任务选择、版本归档、只读恢复。
- 规则中心：真实 `/v1/rules` 数据。
- 审计记录：真实 `/v1/audit/events` 数据。

## 6. 运行与可访问性约束

- 导航与按钮必须使用语义化 `button`，表格使用 `table`。
- 表单字段必须有 `label`。
- 风险不得仅依赖颜色表达，必须有文字标签。
- 375px、768px、1280px 视口均不得发生内容遮挡或水平溢出。
- 页面请求失败必须显示错误信息，不得静默为空。

## 7. 已知非生产边界

- 当前登录仍是前端本地演示账号，不是正式认证。
- 任务、规则和审计业务元数据仍由后端内存 Store 持有，容器重启会丢失。
- MinIO 只持久化附件，不等于 PostgreSQL 业务持久化完成。
